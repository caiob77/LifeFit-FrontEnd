## Tarefa

Adicionar regra de negócio: **desabilitar botão "Iniciar Treino" quando o dia da semana do workday não corresponder ao dia atual**.

---

## Contexto

O componente `WorkoutActions` em `app/workout-plans/[id]/days/[dayId]/_components/workout-actions.tsx` exibe o botão "Iniciar Treino". Atualmente, o botão está sempre habilitado quando o status é `idle`, independentemente do dia da semana.

A página `page.tsx` já possui:
- O `weekDay` do treino (ex: `MONDAY`, `TUESDAY`, etc.)
- Acesso ao dia atual via `dayjs()`

---

## Requisitos

### 1. Passar informação de "é hoje" para o componente

Na `page.tsx`, determinar se o `weekDay` do treino corresponde ao dia atual:

```typescript
const today = dayjs();
const currentWeekDay = today.format('dddd').toUpperCase(); // MONDAY, TUESDAY, etc.
const isToday = weekDay === currentWeekDay;
```

> **Nota**: Verificar se o locale do dayjs está em inglês para que `format('dddd')` retorne os dias em inglês maiúsculo.

### 2. Atualizar interface `WorkoutActionsProps`

Adicionar nova prop:

```typescript
interface WorkoutActionsProps {
  workoutPlanId: string;
  workoutDayId: string;
  initialState: WorkoutSessionState;
  isToday: boolean; // NOVO
}
```

### 3. Atualizar componente `WorkoutActions`

Quando `status === "idle"` e `isToday === false`:
- O botão "Iniciar Treino" deve estar **desabilitado**
- Adicionar texto alternativo ou tooltip explicando que só é possível iniciar no dia correto

Exemplo de implementação:

```tsx
if (state.status === "idle") {
  return (
    <form action={dispatch}>
      <input type="hidden" name="workoutPlanId" value={workoutPlanId} />
      <input type="hidden" name="workoutDayId" value={workoutDayId} />
      <Button
        type="submit"
        disabled={isPending || !isToday}
        className="rounded-full px-4 py-2 font-heading text-sm font-semibold"
      >
        {isPending ? "Iniciando..." : "Iniciar Treino"}
      </Button>
    </form>
  );
}
```

### 4. (Opcional) Feedback visual para o usuário

Quando o botão estiver desabilitado por não ser o dia correto, considerar:
- Exibir tooltip com mensagem: "Disponível apenas no dia do treino"
- Ou alterar o texto do botão para indicar o motivo
