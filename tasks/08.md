## Tarefa


organizacao do meu fluxo de navegacao entre paginas 

## Requisitos técnicos

- Organize o fluxo de navegação entre as páginas da aplicação seguindo esta estrutura:
  - **Página inicial (`/`)**: Deve verificar se o usuário está autenticado. Se não estiver, redirecionar para `/login`.
  - **Após login**: Verificar se o usuário tem dados de treino e plano de treino ativo usando `getHomeData` e `getUserTrainData` de @app/_lib/api/fetch-generated/index.ts.
  - **Se não tiver dados completos**: Redirecionar para `/onboarding` (página criada na tarefa 07).
  - **Se tiver dados completos**: Permitir acesso à página principal/dashboard.
  - **Página de onboarding (`/onboarding`)**: Após completar o onboarding, redirecionar para a página principal.
  - **Todas as páginas protegidas**: Devem implementar a verificação de autenticação e dados completos antes de renderizar o conteúdo.
- Implemente um middleware ou componente de layout que faça essas verificações de forma centralizada para evitar repetição de código.
- Garanta que o botão "Acessar FIT.AI" no topbar da página de onboarding redirecione corretamente para a página principal após o usuário completar o processo.
- Mantenha a consistência do estado de autenticação em toda a aplicação usando o sistema de autenticação do Better Auth.
